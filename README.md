# Auto Poster

Write once. Publish to multiple social platforms.

Planned platforms:

- Telegram
- Bluesky
- Mastodon
- LinkedIn (personal profile)
- Facebook Pages

Runs locally. No account required. No cloud backend. Open source.

> **Status:** early development. Nothing is usable yet.
> Phase 0 (architecture and plan) is complete. See [docs/architecture.md](docs/architecture.md).

## What it will do

1. Write a post.
2. Pick which platforms should receive it.
3. Add images and any platform-specific options.
4. Publish, then see which platforms succeeded or failed, and why.

Your posts, history and credentials stay on your computer. Images are only sent to
the platforms you choose. The project does not collect any data.

## Not supported

Instagram, X/Twitter, TikTok, browser automation, scraping, and unofficial APIs.
